# juliettesaetre.com

Personal academic website, served with GitHub Pages. Plain HTML + one CSS file, no build step.

## Files
- `index.html` (Bio), `cv.html`, `publications.html`, `teaching.html`
- `style.css`: all styling (light and dark mode)
- `images/photo.jpg`: profile photo (add it; the page hides the image until it exists)
- `files/`: put PDFs here (CV, syllabi) and link to them as `files/cv.pdf`

## Editing
Edit the HTML files directly in RStudio or any text editor, then commit and push.
The sidebar is repeated on every page, so a change to the menu or contact links must be made in all four files.
